# Changelog

## 0.1.0

- First standalone SAGA game system targeting Foundry VTT 14.
- Native ApplicationV2 actor and item sheets; no dependency on Simple Worldbuilding.
- Existing character creator and Play Mode connected to SAGA Actor data.
- Sheet buttons for editing and Play Mode.
- Copy importer for module-managed and formula-only exported Actors, with original-source backups.
- GitHub-ready manifest, bundled runtime assets, development source, and public installation documentation.

Experimental release; live Foundry acceptance testing remains outstanding.
